## Content included

Only independently implemented calculation logic, original descriptions and identified own synthetic assumptions are included numerically. Own case assumptions are labelled SYNTHETIC EDUCATIONAL ASSUMPTION. They are not official, verified or PCAF-issued factors. The existing economic/sector proxies originate in CASE_USER_V2 / User v3 assumptions. ECO_ASSET_TEXTILE_S3_DERIVED uses only the own revenue proxy and own turnover assumption; multiplication did not convert any third-party factor into own content.

## Content not redistributed

Redistribution permission not established for this release. External physical factors, benchmarks, gas-specific datasets, period mixes/SIN and GWP values have been externalized. Cited sources remain as references and official URLs. The user obtains values under applicable terms and supplies them in FACTOR_INPUTS with expected unit, period, scope/boundary, source and evidence. Missing values yield n.a./FACTOR_REQUIRED for dependent routes, never an invented substitute.

No official PDF, calculation tool, screenshot, copied dataset or logo is bundled. Historical numerical audit evidence and reinsertion copies are excluded from public distribution. The public matrix replaces external numeric payload with NOT REDISTRIBUTED. A cited link, public access, government origin or free educational use is not treated as permission.
